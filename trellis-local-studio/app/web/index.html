New Generation

TRELLIS.2 is single-image based. Front/back mode stores both images and generates from the selected primary image only.

This is not native multi-view fusion. The secondary image is saved for reference unless a future verified module is added.

Advanced export options

WebP makes smaller GLB files and works in the in-app preview, but Blender often shows an untextured mesh. Leave this off for Blender, Unity, and most DCC tools. Textures are embedded inside the GLB, not saved as separate image files.

1536 generation, 8192 textures, and very high decimation targets may exceed RTX 3090 VRAM. Use Balanced or 1024 generation if a job fails.

Help / Usage

  1. Start the app with ./scripts/run_app.sh.
  2. Open http://127.0.0.1:7860.
  3. Upload an existing PNG, JPG, JPEG, or WEBP image.
  4. Choose Balanced for normal RTX 3090 use, or High Quality for 1536 demo-like mesh detail.
  5. Click Generate 3D Model and wait for the queued job.
  6. Download output.glb from the completed job.
  7. Import the GLB into Blender or Unity with a GLB importer.

For quality closest to the official TRELLIS.2 demo, use the High Quality preset or set Generation resolution to 1536. Use a clean PNG with a transparent background when possible; demo images are curated product photos with alpha masks.

Textures are embedded inside the GLB, not saved as separate PNG files in the job folder. For Blender, leave Use WebP extension off when generating. If an older job used WebP, run python scripts/convert_glb_for_blender.py your-model.glb.

Front/back pair mode is organizational: choose the primary image. TRELLIS.2 does not natively fuse both views in this app.
